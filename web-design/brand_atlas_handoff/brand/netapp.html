넷앱 NetApp

넷앱(NetApp)은 데이터 스토리지, 클라우드 컴퓨팅과 데이터 관리 분야에서 하드웨어·소프트웨어·서비스를 제공하는 미국 기업이다.

기술·전자미국 브랜드로고

최종 업데이트 2026년 9월 12일

넷앱은 어떤 브랜드인가

NetApp은 데이터 스토리지, 클라우드 컴퓨팅과 데이터 관리 분야에서 사업을 운영한다. 사업 포트폴리오는 통합 스토리지, SAN 스토리지, 소프트웨어와 서비스로 구성한다.

핵심 제품은 올플래시 스토리지 어레이, 퍼블릭 클라우드의 스토리지 옵션과 데이터 관리 소프트웨어이다. 다수의 스토리지 솔루션은 자체 개발한 ONTAP 운영체제를 기반으로 공통 기능을 제공한다.

프라이빗·퍼블릭·하이브리드 클라우드와 인공지능 활용 환경을 위한 데이터 인프라 기술도 제공한다. 경쟁사로는 EMC, Hitachi Data Systems, Hewlett Packard Enterprise와 IBM이 해당한다.

넷앱은 어떻게 시작되고 성장했나

NetApp은 1992년 David Hitz, James Lau와 Michael Malcolm이 Network Appliance라는 이름으로 설립했다. 1995년에는 NASDAQ에 티커 심볼 NTAP으로 상장했다.

회사는 오랫동안 Network Appliance라는 상호로 사업을 운영했지만 시장에서는 흔히 NetApp으로 불렸다. 2008년 3월 10일 공식 사명을 NetApp으로 변경했다.

매출은 1995 회계연도 1,500만 달러에서 2004년 처음으로 10억 달러를 넘기며 성장했다.

넷앱의 브랜드 아이덴티티는 무엇인가

ONTAP을 중심으로 여러 스토리지 제품군에 공통 기능을 제공하고 온프레미스와 멀티클라우드 데이터 관리를 연결하는 점이 구분점이다.

넷앱의 대표 제품과 서비스는 무엇인가

NetApp의 제품군은 통합 스토리지와 SAN 스토리지 솔루션, 소프트웨어 및 서비스로 구성한다. 주요 제품은 ONTAP 기반 스토리지, 올플래시 스토리지 어레이, 퍼블릭 클라우드 스토리지 옵션과 데이터 관리 소프트웨어이다.

소프트웨어는 스토리지 네트워크 관리, 성능 최적화와 분석, 랜섬웨어 방어, 백업·복구, 아카이빙과 규제 준수를 지원한다. 클라우드 제품과 서비스로 BlueXP Backup and Recovery, Amazon FSx for NetApp, Azure NetApp Files, Google Cloud NetApp Volumes와 NetApp Cloud Volumes ONTAP을 제공한다.

NetApp Trident와 NetApp Jenkins Framework를 통해 컨테이너 및 DevOps 환경과도 통합한다.

넷앱은 지금 어떤 상태인가

NetApp은 2021년부터 미국 캘리포니아주 산호세에 본사를 두고 사업을 운영한다. 최고경영자이자 이사회 구성원은 George Kurian이며, President는 César Cernuda이고 전 세계 고용 인원은 약 11,700명이다.

현재 진행 중인 2026 회계연도 매출은 69억 3,000만 달러이다. 2026년에는 DataPelago와 JetStream Software를 인수했으며, DataPelago는 완전 자회사로 운영한다.
