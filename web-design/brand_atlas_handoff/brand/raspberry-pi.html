라즈베리 파이 Raspberry Pi

라즈베리 파이(Raspberry Pi)는 영국 잉글랜드의 라즈베리 파이 재단이 기초 컴퓨터 과학 교육을 위해 개발한 신용카드 크기의 싱글 보드 컴퓨터이다.

기술·전자

최종 업데이트 2026년 9월 12일

RP라즈베리 파이

라즈베리 파이는 어떤 브랜드인가

이 제품은 학교와 개발도상국에서 기초 컴퓨터 과학 교육을 증진한다는 목적으로 개발한 소형 컴퓨터이다. 그래픽 처리 장치와 ARM 계열 프로세서, 메모리, 저장 매체용 카드 슬롯을 하나의 보드에 구성한다.

초기 제품은 엘레멘트14·프리미어 파넬과 RS 콤포넌트의 허가된 제조 협정을 통해 제작했다. 재단은 데비안과 아치 리눅스 ARM 배포판을 제공하고 주요 프로그래밍 언어로 파이썬 사용을 촉진한다.

여러 세대와 가격대의 모델을 출시했으며 계산 모듈과 소형 제로 제품으로 구성을 확대했다. 2015년 6월 8일 기준 판매량은 약 500만~600만 대를 기록했다.

라즈베리 파이는 어떻게 시작되고 성장했나

초기 개념은 2006년 아트멜 ATmega 644 마이크로컨트롤러를 기반으로 제작했으며 설계도와 인쇄회로기판 배치를 공개했다. 재단 이사 에반 업톰은 교사와 대학교 관계자, 어린이에게 컴퓨터에 대한 영감을 주려는 컴퓨터 애호가들을 모아 재단을 만들었다.

개발 과정에서는 1981년 에이콘이 만든 BBC 마이크로에서 영감을 받았으며, 최초의 ARM 원형 컴퓨터는 USB 플래시 드라이브와 비슷한 크기로 제작했다. 2011년 알파 보드와 베타 보드를 조립해 시험한 뒤 2012년 2월 29일 판매를 시작했고, 같은 해 4월 최초 구매자에게 제품을 전달했다.

라즈베리 파이의 브랜드 아이덴티티는 무엇인가

교육 목적과 신용카드 크기의 싱글 보드 설계를 결합하고, 낮은 가격대의 여러 모델과 공개된 소프트웨어 환경을 제공하는 점이 핵심 특성이다.

라즈베리 파이의 대표 제품과 서비스는 무엇인가

제품군에는 모델 A와 모델 B 계열, 라즈베리 파이 2, 라즈베리 파이 3 모델 B, 계산 모듈과 라즈베리 파이 제로가 포함된다. 초기 모델은 비디오코어 IV 그래픽 처리 장치와 ARM 계열 중앙처리장치, 용량별 메모리, SD 카드 또는 마이크로SDHC 슬롯을 구성 요소로 사용한다.

2014년에는 임베디드 시스템의 일부로 활용하는 계산 모듈을 출시했고, 2015년에는 쿼드 코어 ARM Cortex-A7 중앙처리장치와 1GB 메모리를 갖춘 라즈베리 파이 2를 출시했다. 2016년 발표한 라즈베리 파이 3 모델 B는 무선랜과 블루투스를 내장하고 브로드컴 BCM2837 64비트 ARMv8 프로세서를 사용한다.

라즈베리 파이는 지금 어떤 상태인가

2015년 6월 8일 기준 누적 판매량은 약 500만~600만 대이며, 영국에서 암스트래드 PCW에 이어 두 번째로 많이 선적된 개인용 컴퓨터를 기록했다. 2015년에는 라즈베리 파이 제로를 출시했고, 2016년에는 무선랜과 블루투스를 기본 내장한 라즈베리 파이 3 모델 B를 발표했다.

재단은 리눅스 배포판 다운로드를 제공하고 파이썬을 비롯한 여러 프로그래밍 언어의 사용을 지원한다.
