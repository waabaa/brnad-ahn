데이터도그 Datadog

데이터도그(Datadog)는 클라우드 규모 애플리케이션의 서버, 데이터베이스, 도구와 서비스를 감시하는 SaaS 기반 관측성 서비스를 제공하는 미국 기업이다.

기술·전자미국 브랜드

최종 업데이트 2026년 9월 13일

DA데이터도그

데이터도그는 어떤 브랜드인가

회사는 클라우드 또는 하이브리드 환경을 관리하는 엔지니어링 팀에 데이터 분석 기반의 관측성 서비스를 제공한다. 서버, 데이터베이스, 도구와 서비스의 상태를 감시하고 대시보드, 경보, 지표 시각화 기능을 제공한다.

클라우드 도입 확대에 따라 AWS, Microsoft Azure, Google Cloud Platform, Red Hat OpenShift, VMware, OpenStack을 지원하도록 사업을 확장했다. 애플리케이션 성능 감시와 보안, 코드 품질, 데이터 관측성, 실험 및 기능 관리 영역도 플랫폼에 편입했다.

회사는 뉴욕에 본사를 두고 Nasdaq에 상장한 공개 기업이다.

데이터도그는 어떻게 시작되고 성장했나

회사는 Olivier Pomel과 Alexis Lê-Quôc가 2010년 뉴욕에서 설립했다. 두 사람은 Ecole Centrale Paris 재학 중 만났으며 이후 Wireless Generation에서 9년 동안 함께 근무했다.

NewsCorp가 Wireless Generation을 인수한 뒤 개발팀과 시스템 관리팀 사이의 마찰을 줄이는 제품을 만들기 위해 창업했다. 초기에는 대시보드, 경보, 지표 시각화를 갖춘 클라우드 인프라 감시 서비스로 출발했으며, 클라우드 도입이 늘면서 지원 대상과 제품군을 확대했다.

회사는 2019년 9월 19일 Nasdaq에서 기업공개를 단행했다.

데이터도그의 브랜드 아이덴티티는 무엇인가

인프라 감시에서 출발해 애플리케이션 성능, 보안, 코드 품질, 데이터와 제품 분석을 하나의 관측성 플랫폼으로 확장한 점이 특징이다.

데이터도그의 대표 제품과 서비스는 무엇인가

주요 서비스는 Infrastructure Monitoring, Network Performance Monitoring, Network Device Monitoring, Serverless Monitoring, Cloud Cost Management이다. 이들 서비스는 클라우드와 하이브리드 환경에서 인프라와 애플리케이션의 신뢰성, 성능, 비용을 관리하도록 지원한다.

2016년에는 Application Performance Monitoring 베타 버전을 공개해 전체 기술 스택을 감시하는 기능을 제공했다. 플랫폼은 Go 기반 에이전트를 사용하며 2024년 10월 기준 750개가 넘는 통합을 지원한다.

인수를 통해 런타임 애플리케이션 보안, 정적 코드 분석, 데이터 파이프라인·품질 감시, 기능 플래그와 실험 기능도 추가했다.

데이터도그는 지금 어떤 상태인가

2024년 기준 회사는 33개국에서 약 6,500명을 고용하며 직원의 약 59%가 미국에 근무한다. 뉴욕, 보스턴, 덴버, 샌프란시스코, 파리, 더블린, 암스테르담, 시드니, 도쿄, 싱가포르에 사무소를 운영한다.

2025년에는 Metaplane과 Eppo를 인수해 데이터 및 AI 작업 감시와 제품 분석의 실험·기능 관리 역량을 확대했다.
