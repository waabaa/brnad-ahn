깃허브 GitHub

깃허브(GitHub)는 개발자가 코드를 생성·저장·관리·공유할 수 있는 미국의 사유 소프트웨어 개발자 플랫폼이다. Git 기반 분산 버전 관리와 프로젝트 협업 기능을 제공한다.

기술·전자미국 브랜드디지털 서비스로고

최종 업데이트 2026년 9월 12일

깃허브는 어떤 브랜드인가

깃허브는 공개 및 비공개 저장소를 통해 소스 코드를 호스팅하며, 특히 오픈 소스 소프트웨어 개발 프로젝트에 널리 사용되는 플랫폼이다. 각 프로젝트에 접근 제어, 버그 추적, 기능 요청, 작업 관리, 지속적 통합, 위키 기능을 제공한다.

표준 Git 명령줄 인터페이스와 데스크톱 클라이언트, Git 플러그인을 통한 저장소 관리도 지원한다. 2023년 1월 기준 1억 명 이상의 개발자와 4억 2천만 개 이상의 저장소를 보유했다고 보고했다.

2023년 6월 기준 세계 최대의 소스 코드 호스트이며, 2024년에는 5억 개 이상의 오픈 소스 프로젝트에서 50억 건 이상의 개발자 기여가 이루어졌다고 집계했다.

깃허브는 어떻게 시작되고 성장했나

운영사인 GitHub, Inc.는 톰 프레스턴워너, 크리스 완스트래스, P. 하이에트가 창업해 2007년 설립했으며, 서비스 개발에는 스콧 채콘도 참여했다.

플랫폼 개발은 2007년 10월 19일 시작했고 수개월간의 베타 기간을 거쳐 2008년 4월 정식 출시했다. 초기에는 창립자들이 자금을 대고 직원을 채용할 수 있을 만큼 수익을 낸 부트스트랩 스타트업으로 운영했다.

2012년 앤드리슨 호로위츠에서 1억 달러를 투자받았고, 2015년에는 시리즈 B 투자로 2억 5천만 달러를 추가 유치하며 성장했다.

깃허브의 브랜드 아이덴티티는 무엇인가

Git 기반 저장소와 개발 협업 기능을 한 플랫폼에 결합하고, 공개 저장소의 포크와 병합을 통해 오픈 소스 개발 참여를 연결하는 점이 구별점이다.

깃허브의 대표 제품과 서비스는 무엇인가

핵심 서비스는 Git을 사용하는 코드 저장소로, 표준 Git 명령을 통해 프로젝트에 접근하고 변경 이력을 분산 관리하도록 지원한다. 저장소별로 접근 제어, 버그 추적, 기능 요청, 작업 관리, 지속적 통합과 위키를 제공해 개발 과정을 한곳에서 관리하게 한다.

공개 저장소 탐색과 포크·브랜치 현황 확인을 지원하며 피드, 팔로워 등 개발자 간 연결 기능도 제공한다. 학교 대상 무료 교육 번들인 깃허브 에듀케이션을 운영하고, npm을 인수했으며, 오픈 소스 코드를 영구 보존하기 위한 깃허브 아카이브 프로그램도 수립했다.

깃허브는 지금 어떤 상태인가

깃허브는 2018년 인수를 완료한 마이크로소프트의 자회사인 GitHub, Inc.가 운영하며, 커뮤니티·플랫폼·비즈니스 측면에서 독립적인 운영을 이어간다. 2023년 1월 기준 전체 저장소 중 최소 2,800만 개가 공개 저장소였으며, 2025년 6월에는 저장소 수가 10억 개를 돌파했다.

2025년 8월 토마스 돔케는 기업가적 활동을 위해 연말에 최고경영자에서 물러날 계획이라고 발표했다.
