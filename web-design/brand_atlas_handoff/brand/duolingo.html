듀오링고 Duolingo

듀오링고(Duolingo)는 언어 학습 웹사이트와 앱, 언어능력평가 시험인 듀오링고 영어 시험을 제공하는 학습 플랫폼이다. 기본 학습은 무료로 제공하고 프리미엄 서비스는 유료로 운영한다.

기술·전자디지털 서비스로고

최종 업데이트 2026년 9월 12일

듀오링고는 어떤 브랜드인가

이 브랜드는 여러 언어를 퀴즈 형식으로 학습하는 웹사이트와 앱을 운영하고 언어능력평가 시험도 제공하는 플랫폼이다. 사용자는 모국어와 배우려는 언어를 선택한 뒤 기초 단계나 레벨 테스트를 거쳐 자신에게 맞는 단계부터 학습한다.

학습 화면에서는 커리큘럼을 확인하고 진도를 진행하거나 기존 내용을 복습한다. 회화, 오답·어휘·스토리 복습, 리더보드, 퀘스트, 스토어, 프로필 등의 기능도 구성한다.

2021년 8월 기준 34개 언어와 94개 코스를 제공하며 전 세계 사용자 수가 3억 명을 넘는 규모이다.

듀오링고는 어떻게 시작되고 성장했나

카네기멜론 대학교 컴퓨터과학부 교수인 루이스 폰 안이 전 세계 수억 명의 사람이 서로 다른 언어를 무료로 번역하도록 하는 방법을 고민하면서 시작했다. 그는 박사과정 제자인 세버린 해커와 함께 아이디어를 구체화했다.

두 사람은 새로운 언어를 배우려는 욕구를 충족시키면서 둘 이상의 언어를 구사하는 사람이 많지 않다는 문제를 해결할 방법으로 언어 교육을 선택했다. 이후 안토니오 나바스, 비키 청, 마르셀 우커만, 브렌던 미더, 헥토르 비야푸에르테, 호세 푸엔테스 등의 개발자가 참여했다.

듀오링고의 브랜드 아이덴티티는 무엇인가

무료 언어 학습을 중심에 두면서 퀴즈형 진도, 복습, 경쟁 기능과 영어 능력 평가 시험을 한 플랫폼에서 함께 제공하는 점이 특징이다.

듀오링고의 대표 제품과 서비스는 무엇인가

주요 사업은 언어 학습 웹사이트와 앱, 언어능력평가 서비스인 듀오링고 영어 시험으로 구성한다. 학습 서비스는 퀴즈형 문제, 커리큘럼 확인, 진도 진행, 오답·어휘·스토리 복습, 회화와 단계별 레벨 테스트를 제공한다.

리더보드에서는 전 세계 사용자와 경쟁하고 프로필에서는 자신과 친구의 이용 현황을 타임라인으로 확인한다. 한국어 사용자에게는 영어, 스페인어, 중국어, 이탈리아어, 프랑스어, 일본어, 독일어, 포르투갈어 과정을 제공하며 음악, 수학, 체스 과정도 운영한다.

듀오링고는 지금 어떤 상태인가

2021년 8월 기준 언어 학습 웹사이트와 앱에서 34개 언어와 94개 코스를 제공한다. 같은 시점의 전 세계 사용자 수는 3억 명 이상인 규모이다.

기본 서비스는 무료로 이용하는 프리미엄 가격정책을 채택하며 듀오링고 플러스는 유료로 운영한다. 언어 학습과 함께 별도의 영어 능력 평가 시험도 제공한다.
