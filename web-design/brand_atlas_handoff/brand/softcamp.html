소프트캠프 SoftCamp

소프트캠프(SoftCamp)는 대한민국의 정보보안 업체이다. 변화하는 근무 환경에 맞춰 데이터 보안과 협업 및 외부 위협에 대한 보안을 제공한다.

소프트캠프는 어떤 브랜드인가

소프트캠프는 정보보안 분야에서 꾸준한 성장을 보여왔다. 백만불 수출의 탑을 수상하고 일본 문서보안 제품 점유율 1위를 기록하며 성과를 거두었다.

대한민국의 주요 금융지주사와 대규모 그룹사에서 문서보안과 영역보안 제품을 표준으로 사용하고 있다. 국제용 보안인증을 취득하여 글로벌 시장 경쟁력 강화에 힘쓰며 코스닥 시장에 상장했다.

보안 클라우드 서비스 통합 브랜드를 출시하고 소프트웨어 공급망 보안 서비스를 제공하는 합작법인을 설립했다. 현재 Document Security Orchestration과 Zero Trust Security 두 가지 보안 전략을 통해 데이터 보안과 협업, 외부 위협 보안을 지원한다.

소프트캠프는 어떻게 시작되고 성장했나

소프트캠프는 1999년 7월에 설립된 정보보안 업체이다. 설립 이래 꾸준히 성장하며 2006년에는 백만불 수출의 탑을 수상하고 2010년에는 일본 문서보안 제품 점유율 1위를 기록하는 등 성과를 거두었다.

대한민국의 대표적인 금융지주사와 KT그룹, 현대기아차그룹, SK그룹, 신세계그룹 등 대규모 그룹사에서 문서보안 및 영역보안 제품을 표준으로 사용하며 기반을 확장했다. 2019년 12월 한국거래소 코스닥 시장에 상장하며 기업 규모를 키웠다.

2021년 5월에는 소프트캠프-엔키의 합작법인인 레드펜소프트가 설립되어 소프트웨어 공급망 보안 서비스를 출시 및 제공하고 있다.

소프트캠프의 브랜드 아이덴티티는 무엇인가

소프트캠프는 Document Security Orchestration과 Zero Trust Security라는 두 가지 핵심 전략을 통해 변화하는 업무 환경에 최적화된 데이터 및 협업 보안을 제공한다. 이로써 기업의 중요한 정보 자산을 보호하고 외부 위협에 대응한다.

소프트캠프의 대표 제품과 서비스는 무엇인가

소프트캠프는 Document Security Orchestration과 Zero Trust Security를 주요 보안 전략으로 삼는다. Document Security Orchestration 제품군은 문서 암호화, 사용자 인증 및 권한 제어, 클라우드 환경에서의 문서 보안 및 공동 편집을 지원한다.

또한 정보 주권 확보, 무형자산 관리, 외부와의 보안 정보 공유 및 협업을 위한 다양한 서비스를 포함한다. Zero Trust Security 제품군은 최소 권한 인증, 보안 원격 접속, 외부 유입 파일의 안전한 재구성 등을 통해 제로 트러스트 보안을 실현한다.

이 외에도 가상화 기반의 비정형 데이터 암호화, 외부 저장매체 파일 검증 등의 솔루션을 제공한다.

소프트캠프는 지금 어떤 상태인가

소프트캠프는 2019년 12월 한국거래소 코스닥 시장에 상장했다. 2020년 11월에는 보안 클라우드 서비스 통합 브랜드인 Security 365를 출시하며 서비스 영역을 확장했다.

2021년 5월에는 엔키와의 합작법인 레드펜소프트를 설립하여 소프트웨어 공급망 보안 서비스를 제공한다. 2022년 6월에는 제로트러스트 보안이 적용된 보안 원격접속 솔루션을 출시하며 변화하는 근무 환경에 대응하고 있다.

다만 2025년에 재무 담당자의 횡령 혐의로 주식 거래가 정지되는 상황을 겪었다.
