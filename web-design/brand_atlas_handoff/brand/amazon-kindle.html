아마존 킨들 Amazon Kindle

아마존 킨들(Amazon Kindle)은 아마존닷컴이 공개한 전자책 서비스이자 이를 이용하는 전용 기기와 애플리케이션을 함께 가리키는 브랜드이다.

기술·전자로고

최종 업데이트 2026년 9월 12일

아마존 킨들은 어떤 브랜드인가

킨들은 전자 종이 디스플레이를 탑재한 기기와 모바일 애플리케이션을 통해 전자책 콘텐츠를 읽도록 지원한다. 전용 기기는 독자적인 AZW 포맷을 사용하며, 콘텐츠는 아마존의 위스퍼넷과 킨들 스토어에서 내려받을 수 있게 구성한다.

위스퍼넷 접속 비용은 부과하지 않으며 컴퓨터 없이도 콘텐츠를 이용하도록 설계했다. 아이폰과 아이팟 터치용 애플리케이션은 전용 기기 밖에서도 킨들 콘텐츠를 읽게 한다.

위스퍼싱크 기술은 킨들 하드웨어와 다른 모바일 기기 사이의 정보를 동기화한다. 전자책 외에도 문서, 이미지, MP3와 오디블 오디오북 파일을 지원한다.

아마존 킨들은 어떻게 시작되고 성장했나

아마존닷컴은 2007년 11월 19일 전자책 서비스와 이를 이용하는 기기인 킨들을 공개했다. 첫 제품은 판매 개시 후 5시간 30분 만에 매진될 만큼 높은 관심을 모았으며, 전용 무선망인 위스퍼넷을 통해 콘텐츠를 직접 내려받는 방식을 채택했다.

2009년 3월 3일에는 아이폰과 아이팟 터치에서 사용할 수 있는 킨들 애플리케이션을 공개했다. 이 애플리케이션과 위스퍼싱크를 통해 전용 하드웨어에 한정됐던 이용 환경을 다른 모바일 기기로 확장했다.

아마존 킨들의 브랜드 아이덴티티는 무엇인가

전용 전자 종이 기기와 모바일 앱, 콘텐츠 상점, 무료 접속 무선망을 하나의 전자책 이용 체계로 결합한 점이 핵심이다.

아마존 킨들의 대표 제품과 서비스는 무엇인가

킨들 전용 기기는 6인치 600×800 픽셀의 4단계 그레이스케일 전기영동 디스플레이와 최대 256MB 내장 저장 공간을 제공한다. SD 카드로 저장 공간을 확장하며 USB 2.0 연결 시 USB 플래시 드라이브처럼 사용한다.

콘텐츠는 AZW를 중심으로 보호되지 않은 PRC·MOBI와 텍스트 파일을 지원하며, HTML·DOC·JPEG·GIF·PNG·BMP 문서를 AZW로 변환하는 이메일 서비스도 제공한다. 킨들 스토어는 책의 첫 장을 무료 샘플로 제공하고 신문·잡지·블로그 구독을 취급한다.

전자 사용설명서와 뉴 옥스퍼드 아메리칸 딕셔너리, 시범적인 웹 브라우징 기능도 포함한다.

아마존 킨들은 지금 어떤 상태인가

킨들은 아마존닷컴의 전자책 서비스와 전용 기기, 애플리케이션을 포괄하며 킨들 스토어와 위스퍼넷을 콘텐츠 공급 기반으로 활용한다. 전용 하드웨어와 아이폰·아이팟 터치용 앱을 위스퍼싱크로 연결해 여러 기기에서 독서 정보를 이어서 이용하도록 구성한다.
