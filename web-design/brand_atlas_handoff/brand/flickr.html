플리커 Flickr

플리커(Flickr)는 개인과 블로거가 사진을 공유하고 저장하며 태그로 분류할 수 있는 온라인 사진 공유 커뮤니티 사이트이다. 웹 2.0의 대표적 프로그램 가운데 하나로 거론된 서비스이다.

기술·전자디지털 서비스로고

최종 업데이트 2026년 9월 12일

플리커는 어떤 브랜드인가

플리커는 개인 사진의 교환뿐 아니라 블로거가 사진을 올려 저장하는 용도로 이용하는 온라인 커뮤니티이다. 사용자는 키워드 태그를 붙여 장소 이름이나 주제에 따른 검색을 쉽게 하고, 인기 태그로 분류된 사진에도 빠르게 접근한다.

사진은 폴더가 아니라 메타데이터를 나타내는 집합과 그 상위 구조인 컬렉션으로 유연하게 조직한다. 오거나이저는 태그와 설명, 집합을 수정하고 야후 맵과 연동한 세계 지도에 사진을 배치하는 기능을 제공한다.

플리커는 웹사이트의 주요 동작을 애플리케이션에서 구현할 수 있는 종합적인 웹 서비스 API도 제공하며, 웹 2.0과 사용자 생성 태그를 보여주는 주요 사례이다.

플리커는 어떻게 시작되고 성장했나

플리커의 창업자는 스튜어트 버터필드와 카테리나 페이크이며, 서비스는 캐나다 브리티시컬럼비아주 밴쿠버의 기업 루디코프가 개발했다. 루디코프는 2002년 설립된 기업으로, 2004년 2월 플리커 운영을 시작했다.

플리커는 루디코프의 웹 방식 대규모 다중 사용자 온라인 게임인 게임 네버엔딩에 쓰인 도구 가운데 하나를 선택해 만든 서비스이다. 루디코프는 플리커를 더 편리한 프로젝트로 판단해 게임 네버엔딩을 폐기했으며, 야후는 2005년 3월 루디코프와 플리커를 인수했다.

플리커의 브랜드 아이덴티티는 무엇인가

플리커의 구별점은 사용자가 만든 태그와 물리적 폴더 대신 메타데이터를 표현하는 집합·컬렉션 구조를 결합한 사진 조직 방식이다.

플리커의 대표 제품과 서비스는 무엇인가

플리커의 핵심 서비스는 사진을 올려 공유하고 저장하며 키워드 태그로 분류하는 온라인 사진 커뮤니티이다. 사용자는 하나의 사진을 한 개 이상의 집합에 넣거나 어느 집합에도 넣지 않을 수 있으며, 여러 집합은 컬렉션과 상위 컬렉션으로 구성한다.

오거나이저는 한 계정에 속한 사진의 태그와 설명, 집합을 수정하고 야후 맵과 연동한 세계 지도에 사진을 배치하는 웹 애플리케이션이다. 에이잭스를 이용한 오거나이저는 데스크톱 사진 관리 애플리케이션과 유사한 기능을 제공하며, 플리커의 웹 서비스 API는 외부 애플리케이션이 웹사이트의 주요 동작을 구현하도록 지원한다.

플리커는 지금 어떤 상태인가

플리커는 2004년 2월부터 운영을 이어가는 온라인 사진 공유 커뮤니티 사이트이다. 야후는 2005년 3월 개발사 루디코프와 플리커를 인수했으며, 근거상 플리커는 야후의 서비스이다.

본사는 샌프란시스코에 있으며, 사진 공유와 저장, 태그 기반 조직화, 웹 서비스 API 제공을 중심으로 운영한다.
