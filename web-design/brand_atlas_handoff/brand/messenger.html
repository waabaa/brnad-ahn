페이스북 메신저 Messenger

페이스북 메신저(Messenger)는 텍스트와 음성 통신을 제공하는 자유 인스턴트 메신저 서비스이자 응용 소프트웨어이다. 페이스북의 웹 기반 채팅과 통합돼 모바일과 주 웹사이트에서 친구와 대화하게 한다.

기술·전자디지털 서비스로고

최종 업데이트 2026년 9월 12일

페이스북 메신저는 어떤 브랜드인가

페이스북 메신저는 페이스북 사용자를 위한 자유 인스턴트 메신저 서비스이자 응용 소프트웨어이다. 텍스트와 음성 통신을 제공하고, 페이스북의 웹 기반 채팅 기능과 통합해 작동한다.

오픈 MQTT 프로토콜을 기반으로 하며 사용자는 모바일 앱과 페이스북 주 웹사이트에서 친구들과 대화한다. 페이스북은 iOS와 안드로이드 버전을 시작으로 블랙베리 OS와 타이젠 버전까지 출시했다.

2014년에는 메인 페이스북 앱에서 메시징 기능을 제거하고 별도 메신저 다운로드를 요구하는 방향을 발표했다. 페이스북은 월간 활동 사용자 수가 10억 명에 도달했다고 보고했으며, 줄임말로는 주로 ‘펨’과 ‘페메’를 사용한다.

페이스북 메신저는 어떻게 시작되고 성장했나

페이스북 메신저는 2011년에 설립됐으며, 페이스북은 2011년 8월 9일 iOS와 안드로이드 버전을 출시했다. 같은 해 10월 11일 업데이트를 통해 블랙베리 OS용 앱도 출시했다.

2014년 4월 페이스북은 메인 앱에서 메시징 기능을 제거하고 사용자가 별도 메신저를 내려받도록 할 것이라고 발표했다. 2015년 7월 13일에는 타이젠 버전을 출시하며 지원 플랫폼을 넓혔다.

데이비드 A. 마커스는 CEO 마크 저커버그의 초대로 페이스북에 가입해 메신저로 이동했다.

페이스북 메신저의 브랜드 아이덴티티는 무엇인가

페이스북의 웹 기반 채팅과 오픈 MQTT 프로토콜을 결합해 사용자가 모바일 앱과 주 웹사이트 모두에서 친구들과 대화하게 한다.

페이스북 메신저의 대표 제품과 서비스는 무엇인가

핵심 서비스는 사용자 간 텍스트 메시지와 음성 통신을 지원하는 자유 인스턴트 메신저이자 응용 소프트웨어이다. 페이스북의 웹 기반 채팅 기능과 통합되어 모바일 환경과 주 웹사이트에서 친구들과 대화하도록 구성한다.

서비스의 통신 기반에는 오픈 MQTT 프로토콜을 사용한다. 모바일 응용 소프트웨어는 iOS와 안드로이드 버전으로 먼저 출시했으며, 이후 블랙베리 OS와 타이젠 버전도 출시했다.

2014년 발표에 따라 메인 페이스북 앱에서 메시징 기능을 제거하고 별도의 메신저를 내려받는 방식으로 분리했다.

페이스북 메신저는 지금 어떤 상태인가

페이스북은 페이스북 메신저가 월간 활동 사용자 수 10억 명에 도달했다고 보고했다. 2014년에는 메인 페이스북 앱에서 메시징 기능을 제거하고 사용자가 별도 앱을 다운로드해야 한다고 발표했다.

이후 2015년 7월 13일 타이젠 버전까지 출시했으며, 데이비드 A. 마커스는 마크 저커버그의 초대로 페이스북에 가입해 메신저로 이동했다.
