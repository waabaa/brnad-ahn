스노우플레이크 Snowflake Inc.

스노우플레이크(Snowflake Inc.)는 미국 캘리포니아주 샌마테오에서 설립되어 몬태나주 보즈먼에 본사를 둔 클라우드 기반 데이터 플랫폼 회사이다. 클라우드 기반 데이터 스토리지와 데이터 분석 플랫폼을 제공한다.

최종 업데이트 2026년 11월 16일

스노우플레이크는 어떤 브랜드인가

스노우플레이크는 클라우드 기반 데이터 스토리지를 제공하는 미국의 데이터 플랫폼 회사이다. 데이터 분석을 지원하며, 최소한의 지연 시간으로 데이터 세트에 대한 동시 접근이 가능한 플랫폼을 운영한다.

이 플랫폼은 Amazon Web Services, Microsoft Azure, Google Cloud Platform에서 운영된다. 2012년 7월 미국 캘리포니아주 샌마테오에서 설립되었으며, 본사는 몬태나주 보즈먼에 있다.

2025년 6월에는 클라우드 기반 PostgreSQL 서비스 제공업체 Crunchy Data의 인수를, 2026년 1월에는 AI 기반 옵저버빌리티 기업 Observe의 인수를 발표했다. 2026년에는 OpenAI와 2억 달러 규모의 파트너십을 체결했다.

스노우플레이크는 어떻게 시작되고 성장했나

스노우플레이크는 2012년 7월 미국 캘리포니아주 샌마테오에서 설립되었다. 위키데이터는 창업자로 Benoît Dageville을 기록하고 있다.

이후 본사는 몬태나주 보즈먼에 두고 있으며, Amazon Web Services, Microsoft Azure, Google Cloud Platform에서 운영되는 클라우드 데이터 플랫폼을 제공해 왔다. 2025년 6월에는 Crunchy Data를 약 2억 5,000만 달러에 인수한다고 발표하며 사업 영역을 넓혔다.

스노우플레이크의 브랜드 아이덴티티는 무엇인가

Amazon Web Services, Microsoft Azure, Google Cloud Platform에서 운영되는 클라우드 기반 데이터 플랫폼으로, 데이터 스토리지와 분석, 동시 접근을 함께 제공하는 점이 특징이다.

스노우플레이크의 대표 제품과 서비스는 무엇인가

핵심 서비스는 클라우드 기반 데이터 스토리지와 데이터 분석을 위한 데이터 플랫폼이다. 이 플랫폼은 최소한의 지연 시간으로 데이터 세트에 대한 동시 접근을 지원한다.

AI 영역에서는 Snowflake Cortex AI를 운영하며, 여기에서 OpenAI 모델을 기본 제공한다. 2025년에 인수를 발표한 Crunchy Data는 클라우드 기반 PostgreSQL 서비스를 제공하는 업체이다.

2026년 1월에 인수를 발표한 Observe는 AI 기반 옵저버빌리티 기업이다.

스노우플레이크는 지금 어떤 상태인가

스노우플레이크는 몬태나주 보즈먼에 본사를 둔 미국의 클라우드 기반 데이터 플랫폼 회사이다. 2026년에는 OpenAI와 2억 달러 규모의 파트너십을 체결하고 Snowflake Cortex AI에서 OpenAI 모델을 기본 제공한다.

같은 해 1월에는 AI 기반 옵저버빌리티 기업 Observe의 인수를 발표했다.
