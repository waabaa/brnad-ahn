# 브랜드 유형 분류 규칙 (Brand Type Classification Rules)

브랜드 아틀라스(brandatlas.co.kr)의 브랜드를 6가지 유형(`brandType`)으로 분류하기 위한 규칙이다.
`brandType` 태깅 작업(사람이든 에이전트든)은 반드시 이 문서의 판단 순서를 따른다. `industry`(산업군) 분류를 대체하지 않고 병렬로 추가한다.

---

## 6가지 브랜드 유형

### Type 1 · 생계형로컬
- 창업자 개인·가족 생계가 시작 동기
- 단일 또는 소수 점포, 투자 유치 이력 없음
- 성장보다 지속·전통·지역성이 핵심
- **규모가 커져도 로컬 정체성·가업 승계가 본질이면 이 유형** (예: 성심당)
- 예시: 석봉토스트, 동네 빵집, 30년 노포, 로컬 카페

### Type 2 · 시장혁신형
- 시장 공백·불편 해결이 시작점
- 스케일이 명시적 목표, 투자 유치로 성장
- 가입자·거래액 등 규모 지표 중심
- **국내 시장 장악이 핵심** (글로벌보다 시장 지배)
- 예시: 카카오뱅크, 쿠팡, 당근마켓, 배달의민족

### Type 3 · 미션드리븐
- 사회·환경 문제 해결이 존재 이유
- **문제 해결 자체가 사업 모델**
- 임팩트가 이익보다 명시적으로 우선
- 소셜벤처·사회적기업, 중소~중견 규모
- 예시: 토니스 초코론리, 소셜벤처

### Type 4 · 레거시대기업
- 산업화 시대(주로 1990년대 이전) 창업
- 제조·중공업 기반, 그룹·계열사 구조
- 사업 다각화로 성장
- 브랜드보다 기업(그룹)이 먼저 존재
- 예시: 삼성, LG, 현대, SK, 포스코, 롯데

### Type 5 · 글로벌스케일업
- 작게 시작해 빠르게 확장
- VC 투자 라운드 명확
- 브랜드·디자인 정체성이 제품보다 강함
- 해외 진출·글로벌 지향, 2000년대 이후 창업 다수
- 예시: 젠틀몬스터, 토스, 무신사, 마켓컬리

### Type 6 · 가치주도대형
- 철학·신념이 사업보다 먼저
- 이미 대형이지만 가치 훼손 안 함
- **성장 거부·속도 조절이 전략**
- 캠페인·선언으로 정체성 표현
- 예시: 파타고니아(현재), REI, 아이코닉스(뽀로로)

---

## 판단 순서 (반드시 이 순서대로 판단한다)

1. **규모와 시기를 먼저 본다**
   - 산업화 시대(1990년대 이전) 창업 + 그룹 구조 → **Type 4 확정**
   - 단일·소수 점포 + 투자 이력 없음 → **Type 1 확정**
   - 그 외 → 2번으로

2. **탄생 동기를 본다**
   - 사회·환경 문제 해결이 존재 이유 → **문제 해결형** (3번으로)
   - 시장 기회·불편 해소가 시작점 → **기회 포착형** (4번으로)

3. **[문제 해결형] 규모와 성장 태도를 본다**
   - 문제 해결이 곧 사업 모델 + 중소규모 → **Type 3**
   - 이미 대형 + 성장 억제도 전략 → **Type 6**

4. **[기회 포착형] 정체성 vs 시장 지배 중 무엇이 핵심인가**
   - 브랜드·디자인 정체성 강하고 글로벌 지향 → **Type 5**
   - 국내 시장 장악·규모 확대가 핵심 → **Type 2**

---

## 중요 원칙

- **규모 숫자가 아니라 브랜드의 본질·정체성으로 판단한다.**
- 로컬 정체성이 핵심이면 규모가 커도 Type 1이다. (예: 성심당 = 대전 로컬 60년 → Type 1)
- 한국 법인은 한국 시장 관점으로 판단한다. (예: 스타벅스코리아 = Type 2)
- 확신이 낮으면 반드시 confidence를 medium 또는 low로 표기한다.
- **Type 1의 판단 순서 조건("그룹 구조")이 애매한 서구 헤리티지 브랜드**(오래된 창업 + 대기업 그룹 편입이지만 제조·중공업 기반이 아닌 럭셔리·소비재 하우스)는 Type 4로 잠정 분류하되 confidence를 medium 이하로 낮추고 `review_needed: true`로 표기한다. 이 규칙의 Type 4 예시가 전부 한국 산업화 대기업이라 서구 명품 하우스에 기계적으로 들어맞지 않기 때문이다.

## 경계 사례 참고 (헷갈릴 때 이 논리를 따른다)

| 브랜드 | 판정 | 이유 |
|--------|------|------|
| 무신사 | 글로벌스케일업 | 편집숍 시작이나 자체 브랜드 강함 + 투자·글로벌 확장 → Type 5 |
| 배달의민족 | 시장혁신형 | 브랜드 개성 강하나 본질은 국내 배달 시장 장악 → Type 2 |
| 파타고니아 | 가치주도대형 | 환경 철학 창업이나 대형 + 성장 억제 전략 → Type 6 |
| 토니스 초코론리 | 미션드리븐 | 노예 없는 초콜릿이라는 문제 해결이 곧 사업 모델 → Type 3 |
| 스타벅스코리아 | 시장혁신형 | 한국 법인은 국내 시장 안착·점포 확대 중심 → Type 2 |
| 성심당 | 생계형로컬 | 대전 로컬 60년, 가업 승계, 지역 고수 → Type 1 (규모보다 정체성) |
| 당근마켓 | 시장혁신형 | 지역 기반이나 중고거래 시장 공백을 플랫폼으로 → Type 2 |

## 출력 형식

`brandType` 필드에 아래 서브필드를 채운다.

```json
"brandType": {
  "primary": "생계형로컬 | 시장혁신형 | 미션드리븐 | 레거시대기업 | 글로벌스케일업 | 가치주도대형",
  "reason": "판단 근거 2~3문장. 판단 순서의 어느 분기를 거쳤는지 포함",
  "key_signals": ["판단에 사용한 핵심 신호 2~4개"],
  "confidence": "high | medium | low",
  "alternative_type": "애매한 경우 두 번째 후보 유형, 명확하면 null",
  "review_needed": true
}
```

`review_needed`는 confidence가 low이거나 `alternative_type`이 있으면 true, 아니면 false.

## entityType — 6개 유형을 적용하기 전에 먼저 확인한다

이 판단 순서는 **영리 상업 브랜드**를 전제로 설계됐다. 아래에 해당하면 6개 유형에 억지로 끼워 맞추지 말고 `entityType: "비상업기관"`으로 먼저 분리한다.

- 올림픽·엑스포 등 일회성 대회/행사 아이덴티티 (예: Tokyo 1964, Sarajevo 1984)
- 미술관·박물관·오케스트라·식물원 등 비영리 문화기관
- 재단·자선단체·공익 캠페인
- 동네·산업단지 재생 등 장소 브랜딩(디벨로퍼·지역조직 주도)
- 대학 부속 연구소 등 연구·교육기관
- 스포츠 협회 등 비영리 단체

```json
"entityType": "상업브랜드",
"institutionCategory": null
```

비상업기관인 경우:

```json
"entityType": "비상업기관",
"institutionCategory": "이벤트·행사 | 비영리·문화기관 | 재단·자선·캠페인 | 장소브랜딩 | 협회·단체 | 연구·교육기관"
```

`entityType: "비상업기관"`이어도 `brandType`은 참고용으로 가장 가까운 유형을 채우되 `confidence`는 medium 이하로, `review_needed`는 true로 둔다. "브랜드 유형 테스트" 등 공개 유입 콘텐츠는 반드시 `entityType: "상업브랜드"`만 사용한다.
