# 브랜드 유형 분류 규칙

## 6가지 유형

Type 1 · 생계형로컬
- 창업자 개인·가족 생계가 시작 동기
- 단일 또는 소수 점포, 투자 유치 이력 없음
- 성장보다 지속·전통·지역성이 핵심
- 규모가 커져도 로컬 정체성·가업 승계가 본질이면 이 유형 (예: 성심당)

Type 2 · 시장혁신형
- 시장 공백·불편 해결이 시작점
- 스케일이 명시적 목표, 투자 유치로 성장
- 국내 시장 장악이 핵심

Type 3 · 미션드리븐
- 사회·환경 문제 해결이 존재 이유
- 문제 해결 자체가 사업 모델
- 임팩트가 이익보다 명시적으로 우선

Type 4 · 레거시대기업
- 산업화 시대(주로 1990년대 이전) 창업
- 제조·중공업 기반, 그룹·계열사 구조

Type 5 · 글로벌스케일업
- 작게 시작해 빠르게 확장
- VC 투자 라운드 명확, 글로벌 지향
- 브랜드·디자인 정체성이 제품보다 강함

Type 6 · 가치주도대형
- 철학·신념이 사업보다 먼저
- 이미 대형이지만 가치 훼손 안 함
- 성장 거부·속도 조절이 전략

## 판단 순서
1. 산업화 시대 창업 + 그룹 구조 → Type 4 확정
   단일·소수 점포 + 투자 이력 없음 → Type 1 확정
2. 탄생 동기: 문제 해결형 → 3번 / 기회 포착형 → 4번
3. 문제 해결형: 중소규모 → Type 3 / 대형+성장억제 → Type 6
4. 기회 포착형: 브랜드 정체성 강+글로벌 → Type 5 / 국내 시장 장악 → Type 2

## 경계 사례
- 무신사 → 글로벌스케일업 (브랜드 정체성 강+글로벌 지향)
- 배달의민족 → 시장혁신형 (국내 시장 장악이 핵심)
- 파타고니아 → 가치주도대형 (대형+성장억제 전략)
- 토니스초코론리 → 미션드리븐 (문제 해결이 곧 사업 모델)
- 성심당 → 생계형로컬 (규모 커져도 대전 로컬 정체성 고수)
- 한살림 → 미션드리븐·사회적기업 카테고리 (출판 카테고리 절대 금지)

## approved / review 판정 기준 (개정)

브랜드 단위 승인은 `brand_type.confidence == high` 여부로만 결정한다. 타임라인 개별 이벤트의 confidence(정확한 투자 라운드·상장 시점·지분 변동 등 세부 사실)는 브랜드 전체를 review로 묶는 게이팅 조건이 아니라 **이벤트 단위의 참고 정보**로만 쓴다.

- `brand_type.confidence: high` → `output/approved/` (타임라인에 medium/low 이벤트가 섞여 있어도 무방)
- `brand_type.confidence: medium | low` → `output/review/`
- 각 타임라인 이벤트는 자신의 `confidence`/`review_status`를 그대로 유지한다. `needs_review`로 표시된 이벤트는 나중에 근거가 보강되면 그 이벤트만 개별적으로 `auto_approved`로 승격한다.

이전 브랜드 아틀라스 492개 브랜드 작업에서 브랜드 전체를 막지 않고 필드 단위로 공개하며 검증을 통해 점진적으로 콘텐츠를 확대한 방식과 동일한 원칙이다. 브랜드 단위 게이팅은 완화하되, 사실 검증 자체를 생략하는 것은 아니다 — 이벤트별 confidence·review_status는 계속 정직하게 기록한다.
