사장님이 할 일 — 따라 하기

제가 대신 못 하는 이유는 하나입니다. 사장님 계정으로 로그인해야 하는 일이라서요.

1

지금 바로 — 네이버에서 숫자 하나 보고 알려주기 30초

가입도, 카드도, 키도 필요 없습니다. 지금 우리 사이트가 네이버에 몇 개 올라가 있는지만 알면 됩니다. 이번 작업 전 숫자는 425였습니다.

  1. 네이버 검색창에 이렇게 그대로 칩니다 → site:brandatlas.co.kr
  2. 결과 화면에 나오는 건수를 저에게 알려주세요
더 정확한 숫자를 원하시면 — searchadvisor.naver.com 로그인 → 브랜드아틀라스 선택 → 왼쪽 리포트 → 사이트 최적화 또는 검색 반영 현황에 나오는 수집/색인된 문서 수를 알려주셔도 됩니다. 어느 쪽이든 어디서 본 숫자인지만 같이 말씀해 주세요. 출처가 섞이면 비교가 안 됩니다.
2

사이트맵 다시 제출하기 약 5분

사이트맵은 “우리 사이트에 이런 페이지들이 있어요” 목록표입니다. 오늘 목록표를 새로 만들고 이미지 1,413장도 처음으로 넣었습니다. 가만 둬도 언젠가 읽어가지만, 직접 제출하면 훨씬 빨리 읽어갑니다. (이 안내는 전과 동일합니다 — 그대로 유효합니다.)

  1. 네이버: searchadvisor.naver.com 로그인 → 브랜드아틀라스 선택 → 왼쪽 요청 → 사이트맵 제출
  2. 칸에 sitemap.xml 입력하고 확인
  3. 구글: search.google.com/search-console 로그인 → 사이트 선택 → 왼쪽 Sitemaps
  4. 똑같이 sitemap.xml 입력하고 제출
“www.brandatlas.co.kr”이 따로 등록돼 있다면 그건 이제 안 씁니다. 오늘부터 www 주소는 전부 www 없는 주소로 자동 이동합니다. 등록은 지우지 말고 그냥 두세요 — 구글·네이버가 알아서 합칩니다.
3

(선택) API 키 발급 — 매주 자동으로 세게 하기 약 15분

1번은 매번 사장님이 직접 봐야 합니다. 이 키를 한 번 받아두면 매주 월요일 새벽에 컴퓨터가 알아서 세서 기록합니다. 안 하셔도 일은 굴러갑니다. 급하지 않으니 시간 될 때 하세요.

  1. ncloud.com 접속 → 회원가입 (네이버 아이디와 별개인 “네이버 클라우드 플랫폼” 계정입니다)
  2. 가입 후 콘솔(Console) 로 들어가기
  3. 왼쪽 위 Menu → All Services 에서 API HUB 를 찾아 들어가기
    (메뉴 이름이 다르게 보이면 화면을 캡처해서 저에게 보내주세요. 제가 짚어드리겠습니다.)
  4. 이용 신청 하고, 쓸 API로 Search(검색) 를 고르기
  5. Application 등록 을 누르면 Client ID 와 Client Secret 두 줄이 나옵니다
  6. 그 두 줄을 저에게 알려주시면 끝. 제가 서버에 넣고 자동화까지 켜두겠습니다.
알아두시면 좋은 것 3가지
· 검색 API는 지금 무료입니다(한시적 무료 요금제). 월 사용 한도도 우리가 쓰는 양보다 훨씬 큽니다.
· 가입 과정에서 결제수단 등록을 요구할 수 있습니다. NCP는 클라우드 서비스라 정상 절차이며, 무료 범위만 쓰면 청구되지 않습니다.
· 9월 30일까지 신규 가입 + API HUB 이용 신청하면 NCP 크레딧 20만 원을 줍니다(발급일로부터 3개월 사용). 하실 거면 이달 안이 낫습니다.
직접 넣고 싶으시면 터미널에 아래 두 줄을 붙여넣고 여기에_붙여넣기만 바꾸세요. echo 'export NCP_APIGW_KEY_ID="여기에_붙여넣기"' >> ~/.bashrc echo 'export NCP_APIGW_KEY="여기에_붙여넣기"' >> ~/.bashrc
